# FYP---sahil-e-baseera

This branch, **`feature/speed-estimation`**, contains the deployment files for the automatic speed-estimation feature.

- [Feature setup and usage](Intelligent%20Traffic%20management/automatic%20speed%20estimation/README.md)
- [Complete experiments, tests, notebooks and generated outputs](https://github.com/safecityfyp/FYP---sahil-e-baseera/tree/feature/experiments/speed-estimtaion)

The feature stays under the project's `Intelligent Traffic management/` folder. Other project features remain on their respective branches.

Clone only the deployment branch to avoid downloading experiment history:

```powershell
git clone --depth 1 --single-branch --branch feature/speed-estimation https://github.com/safecityfyp/FYP---sahil-e-baseera.git FYP-speed-runtime
cd "FYP-speed-runtime/Intelligent Traffic management/automatic speed estimation"
```
